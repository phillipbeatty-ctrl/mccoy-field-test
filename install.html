Install on iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button. On iPad, it is usually in the toolbar.
  3. Scroll and choose Add to Home Screen.
  4. Confirm the name reads Field Coach, then tap Add.
  5. Open Field Coach from the new Home Screen icon and sign in.
An older Home Screen icon named McCoy will not rename reliably on iOS. Remove that old icon, then add this updated Field Coach web app again.

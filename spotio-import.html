McCoy SPOTIO Import

Admin-only capture bridge

1. Sign in as McCoy Admin

2. Capture SPOTIO data

Open SPOTIO in another desktop browser tab while signed in. Open Developer Tools → Console, paste the contents of spotio-capture-helper.js, then browse your Lead/Pipeline/Map views so SPOTIO loads the records.

When finished, run MCCOY_SPOTIO_CAPTURE.download(). A JSON file will download to your computer.

Open capture helper code

3. Upload capture to McCoy

Captured data is stored in an Admin-only import batch. It is not exposed to reps. The next normalization pass will map SPOTIO lead IDs, addresses, coordinates, owners, stages and supported custom fields into McCoy Lead Pool records.
